# Experiment 8: PGP Email Encryption and Digital Signatures Using Thunderbird

## Aim
To demonstrate secure email communication by sending and receiving PGP-encrypted and digitally signed emails using Mozilla Thunderbird and OpenPGP.

## Software Requirements
- Kali Linux / Windows
- Mozilla Thunderbird
- Two email accounts
- OpenPGP support
- Internet connection

## Theory

**Pretty Good Privacy (PGP)** is a cryptographic system used to secure email communication. It provides confidentiality, integrity, and authentication through encryption and digital signatures.

OpenPGP uses public-key cryptography:

- **Public Key:** Shared with others to encrypt messages and verify digital signatures.
- **Private Key:** Kept secret and used to decrypt messages and create digital signatures.

### Security Services
1. **Confidentiality:** Ensures only the intended recipient can read the email.
2. **Integrity:** Ensures the message has not been modified.
3. **Authentication:** Verifies the sender's identity through digital signatures.

## Tools Used
- Mozilla Thunderbird
- OpenPGP
- Email accounts

## Procedure

1. Install and launch Mozilla Thunderbird.
2. Configure an email account.
3. Open Account Settings and navigate to OpenPG
